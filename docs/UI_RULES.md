# UI 与交互设计约束

目标：用户在首屏看懂自己应选择哪种授课语言，随后能快速判断能否申请。

## 信息层级

- 留学主页：品牌与界面语言 → 主标题 → 英语／捷克语授课选择 → 学位等辅助入口。
- 不用大幅风景图、轮播、营销标语占据首屏语言选择的位置。
- 界面语言控件标“简体中文 / English / Čeština”；不使用国旗代替语言名称。
- 授课语言控件有独立文字标签，不使用与界面语言相同的无标题地球图标。
- 两种授课语言同等醒目；不得把捷克语放入隐藏的高级筛选。
- 状态同时使用文字和图形，不能只用红绿颜色区分。

## 视觉系统

- 使用 design/tokens.json 作为初始变量源；允许有证据的统一调整，禁止局部随意改色。
- 基础：浅灰白背景、白色信息卡、深海军蓝正文、蓝色主要动作、细边框。
- 留白采用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px；同类组件间距一致。
- 正文桌面与手机均不少于 16 px，辅助文字通常不少于 14 px；正文行高 1.6，中文长文 1.7–1.8。
- 字体优先系统字体，提供中文、拉丁字母和捷克语变音符号的可靠回退；如使用品牌字体则自行托管且核查许可。
- 容器最大宽度 1200 px；桌面常规侧边距 32 px，手机 16 px。
- 卡片圆角 12 px，控件 8 px；阴影轻微，仅用于浮层或有限层级，避免所有卡片悬浮。
- 图标使用同一套 SVG 风格并带可访问名称；不以 emoji 作为主导航图标系统。

## 页面布局

- >= 1024 px：左侧 260–280 px 筛选栏，右侧结果；结果可切卡片与紧凑列表。
- 768–1023 px：收起筛选或缩为顶部筛选；避免狭窄双栏。
- < 768 px：单列卡片，英语／捷克语选择纵向排列，筛选抽屉包含结果数与“应用筛选”。
- 主要页面不得产生意外横向滚动（比较页已按 A80 移除）。
- 不固定组件高度来容纳单一语言，英文与捷克文扩长后应自然换行。

## 组件行为

- 授课语言选择：完整卡片可点，键盘可操作，选中状态有文字／勾选提示。
- 筛选：选中条件显示为可移除标签；清空后保留界面语言；明确“全部”和“未知”的不同含义。
- 卡片：最多一个主要动作，其他操作用清楚的次级按钮；卡片/详情不提供收藏或比较动作（A80）。
- 日期：显示日期及状态文本；倒计时为辅助，不能替代绝对日期。
- 未公布字段用“未公布”，不能用含混的短横线或假装加载。
- 空结果：解释当前筛选，提供移除条件入口；不悄悄混入其他语言项目。
- 请求失败：显示可重试状态；数据过期显示核验日期；加载使用稳定尺寸骨架，减少跳动。
- 表单：可见标签、就地错误、保留输入；提交按钮显示处理中与结果。
- 手机浮动按钮不得遮住内容、语言控件、Cookie 控件或系统安全区域。
- 地图是辅助视图，学校列表是可核对的数据入口。低缩放时相邻学校显示为带数量的原生按钮，激活后放大；街道级恢复每所学校的独立按钮。桌面端鼠标指针位于地图时，普通滚轮直接缩放，不要求按住 Ctrl 或 Command，也不显示协作手势提示。外部瓦片失败或超时必须显示三语状态并切换到项目内置概览，列表、筛选、手动切换和重试仍可用。

## 可访问性与性能目标

- 实施时以 WCAG 2.2 AA 为验收参考；普通正文对比度 >= 4.5:1，大字 >= 3:1，关键控件边界与焦点 >= 3:1。
- 常用触控目标至少 44×44 px；有明显键盘焦点，无键盘陷阱；抽屉和对话框关闭后焦点返回触发处。
- 200% 缩放可用；页面有语义标题顺序、跳过导航入口、准确的 lang 属性与表单关联标签。
- 动画通常 120–200 ms，尊重 prefers-reduced-motion；无自动播放背景视频。
- 核心文字、筛选、结果与详情不依赖第三方翻译、Google 字体、国外地图或社交脚本加载。
- 目标 LCP <= 2.5s、CLS <= 0.1、INP <= 200ms；上线前实验室检测，上线后再用足量真实用户数据验证。不能把本地测速等同大陆可用性。

## 设计交付与评审

先产出主页、项目列表、项目详情、岗位详情的桌面与手机页面，再逐语言验收。
截图至少覆盖 390 px、768 px、1440 px，使用含长捷克文名称、费用未知、已截止等状态的数据。
美观验收关注：对齐、字体层级、留白、统一控件、语言选择首屏可见、长文不溢出。
可用性验收：首次接触者能独立切换 UI、选择英语授课、找到语言门槛并打开官方申请入口。

## 岗位卡片直达规则（用户新增要求）

- 岗位标题和“立即申请”使用真实 applicationUrl 的普通链接，点击直接打开官方申请目标，不经过本站登录或中间广告页。
- 可另设“查看本站解读”次级入口，不能替代标题直达行为。
- 显示外部链接提示与官方目标域名；官方指定第三方招聘系统属于可接受申请入口，须有官方来源证明。
- 缺独立表单而采用邮件申请时，明确标为“查看官方申请说明”并链接公告；邮件发送始终由用户操作。
- 已关闭岗位从公开列表移除；旧详情页可显示“已关闭”墓碑并禁用申请。
- 静态缓存同样遵循关闭状态覆盖和过期时间，三语同步下架，不允许一种语言仍可申请。

## 必显学校标签与申请窗口

学校名下并列性质标签和中留服参考状态，鼠标悬浮不是唯一查看说明的方式；手机可点击查看证据和日期。
认证状态文案：“中留服查询可查 / 中留服暂未收录（捷克官方认可） / 待核验”；若有官方特别提示，优先展示并说明适用范围。禁止“100% 可认证”或“公立必认证”。
项目与岗位卡片均展示“开始日期 — 截止日期”和官网有依据的轮次。起始未知显示“开始日期未公布”，不能隐藏已有截止日期。
列表突出当前开放轮次，详情按时间展开所有已核验轮次。多轮同时开放则明确适用人群；不得混合成一个虚假的连续申请区间。
固定文案示意：“第 2 轮 · 2027-04-01 至 2027-05-31”仅为设计示例，不能当真实招生记录。
