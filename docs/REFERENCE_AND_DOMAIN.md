# 参考站公开实现与域名成本

## 本次实际检查

2026-09-06 使用本机 Scrapling 0.4.9 GET 成功读取 https://www.guanfu.online/ 的公开页面；事实摘要保存在 reference-inspection.json。原始页面放工作目录，不作为本站正式数据交付。

可确认：

- HTML 内嵌 `window.__UNIS__` 与 `window.__PROGRAMS__` 两组 JSON 数据。
- 此次快照分别为 1521 条学校／机构条目和 1588 条项目条目。这些是原始记录数，不等于独立有效高校数。
- 页面内的 `filterPrograms()` 与 `filterUnis()` 对数组执行浏览器端筛选。
- 页面可见脚本没有发现 fetch() 调用，外部脚本为 Leaflet 地图库；此次页面数据无需逐次搜索远端数据库。
- 内嵌学校条目的计数字段显示 33 个条目已有专业；51 个标记 FH 的条目中该计数均为 0。须注意原站分类准确性和统计字段本身未独立核验。
- 下载后的提取 HTML 约 1.83 MB，包含大量数据；这不是网络压缩传输大小，也不是实测首屏性能。
- 页面脚本按 MM-DD 比较申请窗口；其 `windowOpen` 在存在结束日期但没有开始日期时直接返回 true。这说明本项目应保留完整年度／轮次与未知状态，不能照抄该开放判断。

需要纠正前期理解：页脚仍称专业来自 TUM/LMU，但当前内嵌记录还涉及其他学校，不能再断言它只覆盖这两所。公开页脚与实时数据口径可能不同。

可以合理推断的架构：先在后台／本地采集和整理学校数据，再生成带内嵌 JSON 的页面，由浏览器筛选与地图展示。页面既可能预先构建，也可能服务端生成；仅凭这一响应无法区分。

不能确认：爬虫究竟用 Python、Scrapy、Scrapling、Playwright 还是其他工具；后台数据库；调度周期；部署供应商；完整解析规则。本次未发现公开源码仓库链接，不能把推断当事实。

对本站的启发：可以采用离线采集与静态发布节约成本，但需要数据核验、分片分页与三语版本管理；不将全量三语数据内嵌每个首屏。域名后缀与爬虫能力无关。

## .online 不是最省钱的通用答案

取 2026-09-06 同一注册商 Namecheap 当前一年报价作可比示例：

| 后缀 | 首年页面促销 | 一年续费 | 首年加两次续费的估算 |
|---|---:|---:|---:|
| .online | $0.98（限额活动） | $34.98（促销续费） | $70.94 |
| .com | $10.98（一般页面促销） | $18.48 | $47.94 |

按当前价格不变估算，.com 这组方案三年便宜 $23；不是锁价承诺，也不是多年度一次购买报价。未含税费、可能的 ICANN 附加费；溢价域名不适用。新用户 .com 另有 $6.79 优惠条件，最终以下单页为准。

来源：
- https://www.namecheap.com/domains/registration/gtld/online/
- https://www.namecheap.com/domains/registration/gtld/com/

不同注册商会有更低或更高价格，因此此比较不证明 .com 在所有地方最便宜；它足以说明不能用 .online 首年便宜推断长期最省钱。
选择时查普通域名首年、续费、转入、三年总成本与可备案条件。若只做原型，托管平台提供的免费子域名可暂时避免域名费，但托管额度与大陆可访问性仍需单独核验。
目前没有替用户注册、购买域名，也未确定可用品牌名。
