- D02 已确定：留学入口首先按英语／捷克语授课分流，界面语言独立。来源：用户明确要求。
- D03 已确定：直观、美观、易懂；以 UI_RULES 的具体布局和验收落实。
- D04 已确定：难采集网页使用本机 Scrapling；已检查 CLI，并已实现登记来源的普通／动态采集与失败记录。具体来源仍须逐次保留真实运行证据，不能由解析器测试推断为已抓取全库。
- D05 已确定：OPM 指 ISO 19450，使用 DOT 交付。当前版本采用 ISO 19450:2024，公开映射差异。
- D06 设计决定：并列展示两种授课语言，不依据中文 UI 自动选择英语项目。
- D07 设计决定：岗位库独立于学位项目库，用工作语言和博士要求筛选。
- D08 设计决定：事实与译文绑定版本，三语审核后发布；过期／撤回状态及时更新。
- D09 性能选型：Go 在线服务，TypeScript/Astro 静态前台＋Svelte 局部交互，Python/Scrapling 离线采集，SQL/PostgreSQL；Node 仅构建使用。来源：用户要求综合性能和启动速度。
- D10 数据库建议：试运行用 Supabase Free 并独立备份，正式运营按可用性和配额决定升级；尚未开户或购买。
- 待后续决定：品牌、域名、部署区域、技术栈具体版本、初始学科与学校范围、内容审核人员。

- D13 实施细化：以 120 小时间隔持久调度；已知截止即时计时，补充每日岗位轻量核查；网络失败与真实关闭分开处理。

- D14 用户确定：显著标注学校性质及中留服认证相关信息；采用官方查询参考和来源日期，不能承诺个人获认证。
- D15 用户确定：项目／岗位申请起止时间、官方存在的轮次必须显示。未知不补造，轮次关闭和整个机会关闭分别处理。
- D16 用户确定：先只做查理大学的录取页示踪。初始范围限于 MFF 英语 Computer Science 与捷克语 Informatika 本科各一条；后续发布边界由 D23 取代。登记册库存始终不能写成可申请 offering。
- D17 用户确定：查理大学示踪完成后继续。下一项为马萨里克大学信息学院示踪：捷克语 Informatika 本科 + 英语 Visual Informatics 硕士（FI 本科只有捷克语，不编造英语本科）。
- D18 用户确定：先把其他捷克学校都做了，申请入口必须真实可打开，不能链到 404。54 所登记高校均核验官方电子申请／招生页；打不开的学校不放申请按钮。能打开申请系统仍不等于当前开放申请。
- D19 用户确定：把查理大学与马萨里克大学示踪接到学位项目列表。界面样例与示踪同时进入授课语言检索；当时暂不进入发布目录。D23 建立不可变发布包后，该阶段性限制已被取代，当前以“范围有限”标示并随活动快照发布。
- D20 用户确定：界面语言切换独立于浏览器前进／后退。从中文切到英文或捷克语后再按返回，不得回到该页的中文界面。
- D21 用户确定：地图提前合并到主站是为了观察集成效果，不以“原型应先完成”为由撤回。当前继续在正式组件上迭代并保留可切换的内置概览图。
- D22 地图实现边界：当前交互层是 MapLibre 加 OpenStreetMap 在线栅格瓦片，不描述为自托管 PMTiles，也不承诺中国大陆延迟、可达率或月成本。连续瓦片错误或 12 秒超时自动回退至项目内置的 14 州概览图；真实大陆运营商和真机触屏结果取得后再决定底图服务与自托管方案。
- D23 发布决定：`data/published/current.json` 是唯一活动版本指针。候选先复制到唯一 staging 并通过固定文件集合、外键、证据、URL、资格和逐语种源哈希审核门禁，再写成不可变快照并切换指针。构建启动时固定一个快照版本，只从该版本派生浏览器资源；`--force` 不得绕过业务门禁。
- D24 调度决定：本地参考实现用操作系统文件互斥锁和带拥有者的持久租约保护队列；抓取、解析或分页不完整均记失败且不推进 `lastSuccessAt`，失败来源仍计算 SLA 并按退避时间重试。部署后的常驻调度仍按既定架构落在 Go 后台任务；当前 Python worker 通过测试不代表自动采集已开启。
- D25 关闭状态传递：已核验关闭通过独立版本化安全覆盖到达公开表面；网络失败不是关闭；快照回滚不能重新打开之后的覆盖。完整内容仍走不可变快照审核。
- D26 生产 API：默认绑定 `data/published` 已校验发布，拒绝 fixture，除非显式 `CATALOG_ALLOW_FIXTURE=1`。Go 调度器计划调用现有 Python 命令，不重写解析器。
