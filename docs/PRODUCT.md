# 产品需求

## 用户和核心任务

- 不会捷克语的中文用户：用中文查英语授课项目，看清英语证明及额外捷克语要求。
- 准备学习捷克语的用户：查捷克语授课项目，比较语言门槛和准备路径。
- 英语、捷克语用户：能用自己的界面语言完成相同任务，无语言功能降级。
- 硕士毕业生：查不要求博士学位的带薪研究或技术岗位，并明确是否必须注册博士。

## 入口与流程

全局顶栏：品牌｜学位项目｜带薪科研｜申请指南｜简体中文 / English / Čeština。（“我的清单／比较”按 2026-09-12 A80 所有者决定移除。）

首次进入留学主页，主标题下立即出现“你想用哪种语言学习？”：

1. 英语授课：说明需检查各项目英语要求；部分项目可能另有实习、临床或活动的捷克语要求。
2. 捷克语授课：说明需检查各项目捷克语要求；不预设所有项目同一语言等级。

两张卡片同等大小和视觉权重；下方次级入口“查看全部授课语言”。学位、学校、城市等后置。
用户点选即进入结果，不再要求完成问卷。显式选项可记住，但始终可见、可改、可清除。
直达项目详情无需先选语言，详情顶部突出该项目授课语言。直接打开列表且无语言参数时，列表顶部仍把语言选择放在第一位。
科研入口全局可见，不要求科研用户先选授课语言。

## 路由建议

- /{locale}：语言优先留学入口。
- /{locale}/programmes?teachingLanguage=en：英语授课项目。
- /{locale}/programmes?teachingLanguage=cs：捷克语授课项目。
- /{locale}/programmes/{offeringId}：具体语言版本及入学批次详情。
- /{locale}/institutions/{id}：院校详情，项目仍按授课语言组织。
- /{locale}/research-jobs、/{locale}/research-jobs/{id}：科研岗位。
- /{locale}/guides：申请指南。/{locale}/saved 与 /{locale}/compare 已随 A80 移除，旧链接重定向至项目列表。

URL 是可分享筛选状态；界面语言切换只改变 locale，不改变实体 ID 或搜索条件，也不写入浏览器后退记录。

## 项目结果

第一组筛选：授课语言。后续：学位、学科、城市、预算、申请状态、应用／实践导向、院校类型。
卡片依次展示：项目名称、学校与城市、授课语言、学位与年限、学费口径、截止日期、核验日期。
语言详情分别显示：授课语言、入学语言证明、其他必需语言、学习期间附加语言要求；未说明就明确显示未知。
英语项目不等于不需要任何捷克语，捷克语项目也不自动等于完全免费。
预算筛选对币种、计费周期保持透明；未公布费用不当作 0 参与筛选。
默认排序为已核验且申请开放的机会优先，截止日期排序可选；不提供虚假的录取概率。

## 项目详情

顶部摘要：语言、资格、费用、轮次、状态；下面依次为申请要求、时间线、材料、课程与实习、学校、来源。
“去学校官网申请”是外部跳转，不能表现为站内已提交申请。
A80（2026-09-12 所有者决定）：无收藏、无比较、无任何公开用户注册或账户；网站为匿名浏览，访客筛选、阅读详情后前往官方渠道申请。取代本文件较早的本地存储收藏/比较要求。

## 科研岗位

第一组筛选改为“硕士可申请 / 博士注册要求 / 工作语言”，不借用授课语言字段。
展示雇佣或奖学金性质、工资是否公布、税前税后、周期、实际工时、合同期限、资格证据和工作地点。
明确区分“不要求博士学位”与“不要求注册博士”。工资未公布与未确认带薪是两个状态。
主“带薪科研”库仅发布已确认有薪资或报酬证据的机会；报酬数值可未知。其他线索留在审核后台。
博士后不进入默认硕士可申请结果。确认关闭／截止的岗位自动从公开招聘列表下架，保留内部归档；旧收藏与详情只显示关闭状态并禁用申请。岗位标题及“立即申请”直接链接官方申请页，站内解释通过独立“查看本站解读”入口提供。

## 第一版与后续

第一版：完整三语浏览、语言优先筛选、项目与岗位详情、来源与纠错、基本审核发布（比较/收藏已按 A80 移除）。
后续方向（A80 之后）：提醒订阅等无需账户的公开能力，前提是数据维护先达标。不重建账号、收藏或比较。
暂不做代申请、自动发送邮件、支付、聊天机器人或自动录取评分。

## 五天刷新、广覆盖与申请直达

按 docs/REFRESH_POLICY.md 执行。高校范围以捷克现行官方名录为基线，覆盖公立、国立、私立与应用／职业导向高校，不按排名排除学校，不因缺英语页面漏掉捷克语来源。
学校名录覆盖、已接入来源覆盖、项目收录完整度分别统计，不用学校数量冒充项目覆盖。页面展示的“最新”必须指明是来源抓取、事实核验还是正式快照发布时间；完整读取一个目录不等于完整覆盖全部学校的招生窗口或院系岗位。
五天采集属于待实现的网站后台任务，不是本地聊天提醒。任务在部署环境持续运行，不依赖个人电脑开机。
高波动来源按独立周期运行：已知岗位状态 1 小时、全部已登记岗位目录 4 小时、DZS 项目目录及开放信号 2 小时、CZU 英语目录 2 小时、CZU 捷克入口本科／硕士目录 2 小时、CZU 博士学院证据 2 小时；周期之外仍有网络重试、三语人工审核和安全发布延迟，界面不得宣传“瞬时实时”。
岗位卡片标题和主要动作一键到官方申请页；不要求本站登录或先进入本站详情。无独立申请系统而仅接受邮件时，跳转明确给出申请办法的官方公告，显示“查看官方申请说明”，不伪造申请表。

## 学校性质、中留服参考与多轮申请

学校卡片、项目详情、比较表显著标明公立／私立／国立／待核验；筛选保留捷克法定性质，不强行二分。科研机构若不是高校，性质标为科研机构适用类别，不套大学性质。
中留服信息单列“中留服认证参考”：已在官方认证院校查询中核实的学校显示“中留服查询可查”，附来源和查询日期；未查到与待核验分别显示。不得标“保证认证”。官方风险公告单列，不能用绿色可查标签覆盖风险。
授课语言始终是第一分类，学校性质和认证参考是后置筛选。
学位项目与科研岗位均展示申请开始、截止、状态；官网公布轮次时显示第 N 轮和原文轮次名称。未写轮次则显示“未公布轮次”，不自动当第一轮。
同一专业按年度、语言轨道、适用申请人和轮次分别保存。第一轮截止但第二轮开放时，仍显示该专业可申请并突出第二轮；补录仅在有名额时开放，未确认时显示条件说明。
岗位关闭与某一申请轮次结束分别判断；只结束一个轮次且后续轮次开放的岗位不整体下架。详见 RECOGNITION_AND_WINDOWS.md。
