# 三语独立运行规则

## 两套独立概念

- uiLocale：zh-CN / en / cs，控制导航、标签、内容译文及格式。
- teachingLanguage：en / cs / 其他 BCP 47 码，描述项目实际授课语言。
- workingLanguages：岗位的工作语言集合，与上面两者均不同。
- cs 是捷克语语言码；cz 是国家码，不用于语言文件、lang 或 locale 路由。

## 路由和持久化

显式 URL locale 优先，其次用户已保存选择，其次浏览器支持语言匹配，最后默认 zh-CN。
页首与手机菜单均提供同等功能的语言切换；任何页面最多两次操作完成切换。
切换时保留实体 ID、授课语言、筛选、排序、分页、收藏、比较和未提交表单；搜索框输入不可丢弃。
用户明确选过的授课语言可存为偏好；不得从浏览器语言、IP 或 UI locale 自动推断。
收藏用实体 ID 存储，不用翻译后的名称；切换语言不重复产生收藏。

## 翻译范围

静态词条：导航、筛选、按钮、状态、错误、空结果、帮助、表单、隐私、元数据、可访问名称。
动态核心内容：项目／岗位显示标题、摘要、资格、语言要求、费用说明、申请材料、合同说明、申请步骤。
学校官方名称、学位缩写、专有名词和原始证据保留官方写法；无约定中文译名时保留原名并给说明，不编造官方中文名。
完整原始公告可以用原文附于三语结构化摘要之后，标明源语言，不声称原文已翻译。

## 内容与发布

静态词条放 locales/{locale}.json，键集合完全一致；初始词条是种子，实施新增界面必须同时扩充三语。
生产构建发现缺键或空值即失败，不静默回退英语。开发环境可显示显眼缺译键，但不得发布。
动态内容记录 sourceLanguage、sourceHash、translations、translatedFromHash、reviewStatus、reviewedAt。
翻译状态：missing / draft / reviewed / stale。正式核心内容三语均 reviewed 且对应最新源文方可发布。
源文更新使受影响译文 stale；后台重译与复核后发布新版本。截止／撤销等安全状态可先更新并标记详情待核验，不能继续显示旧的可申请状态。
自动翻译在后台进行，允许先生成草稿，再人工核对。浏览器不调用翻译服务生成关键界面。
学历、否定词、学费单位、工时、税前税后、是否必须读博等内容必须做语义复核，不能仅检查“有译文”。

## 格式与搜索

金额存数值、币种、计费周期、税务口径，显示用 Intl.NumberFormat；翻译不得转换或改写原始金额。
日期存 ISO 值、精度、源时区；显示用 Intl.DateTimeFormat。只有日期而没有时间的截止不能编造精确时间。
默认展示截止所在地时间及当地日期；用户本地换算为补充。Europe/Prague 必须正确处理夏令时。
不拼接翻译句子；复数与参数使用可靠消息格式库，捷克语须覆盖 one / few / other 等实际需要的形式。
搜索索引包括三语译名、官方原名和经审核的别名；容忍捷克变音符号缺省输入；中文搜索可匹配英语项目名。
HTML lang 与页面语言一致；原文块独立声明 lang。SEO 标题描述与 hreflang 使用各自语言版本。

## 验证

断开 Google Translate、Google Fonts 和其他翻译服务后，在三语中完成搜索、查看、比较和收藏。
同一英语项目用中文和捷克文查看，资格、费用和截止必须一致。
三语核心术语表在 locales/glossary.json；初稿捷克文仍需熟悉捷克高校术语的人员复核。
