## 优先顺序

官方结构化入口／公开 API → 官方 HTML → 官方 PDF → 公开动态页面。聚合站只用于发现，资格与工资回到雇主／学校核验。
采集离线在服务端运行，不让访客浏览器即时爬学校官网。
尊重站点访问条件、robots 和速率；按域名限速，建议起点一个并发、请求间隔 2–5 秒，遇 429／503 按 RFC 9110 Retry-After（秒或 HTTP-date）作为最早重试时刻。延迟超过进程内上限则写入来源／主机冷却并交给调度，不得睡一小时，也不得把限流写成岗位关闭。无头或非法 Retry-After 仍用 3 秒、12 秒两次有界本地退避。

## 难网页必须升级到本机 Scrapling

1. 读取返回状态和正文。HTTP 200 不等于成功，登录页、空壳和验证页都是失败结果。
2. 普通提取缺正文、漏语言／费用／截止等目标区块时，先用 Scrapling get 存原始 HTML。
3. 依赖 JavaScript、分页或动态内容时，用 Scrapling fetch；根据真实页面观察结果指定 wait-selector，不猜选择器。
4. 保留 HTML 证据后再生成 Markdown／结构化数据。必要时使用 CSS selector 精确提取。
5. 同源浏览器英文页与捷克文页可能不同；逐页记录 URL 与实际源语言，不能以 UI locale 代替源语言。
6. 持续失败：记录状态、时间、工具、失败原因与缺失字段，进入人工队列；优先找官方替代页面或 PDF，不编造结果。
7. 不绕过登录权限、付费墙或访问控制；本机工具具备某命令不等于每种用法都必要。

## 本机已核查语法示例

以下 URL 占位必须替换为来源注册表中的官方 URL；示例不会自动执行。

```powershell
scrapling extract get "https://OFFICIAL_HOST/PAGE" "work/raw/page.html" --timeout 30
scrapling extract fetch "https://OFFICIAL_HOST/PAGE" "work/raw/page.dynamic.html" --headless --timeout 45000 --wait 1500
```

get timeout 单位是秒；fetch timeout / wait 单位是毫秒。执行前创建输出目录；所有外部命令须检查退出码。
本次已用 get 实际读取参考站并收到 HTTP 200，提取到内嵌数据和脚本。2026-09-06 用同一 get 收获查理大学 SIS 录取详情（`id_obor=34738` / `34456`）及 MFF 院系条件页，保存于 `work/raw/2026-09-06/cuni-*.html`。动态 fetch 仅核查语法，浏览器实际抓取仍待验证。遇环境网络限制应按环境权限申请联网，不能绕过限制或把失败归咎于目标网站。
如缺浏览器依赖，先记录缺什么，再按环境权限安装；不要重复盲目重装全部环境。

## 提取与更新

逐字段保存证据、源语言、内容哈希、抓取时间、解析器版本和规范 URL。
网络成功时间与人工核验时间分开存；抓取成功不得直接标已核验。
稳定来源每隔五天（120 小时）完成一轮全体已登记捷克高校资料采集。高波动来源独立执行：已知岗位状态 1 小时、全部已登记岗位目录发现 4 小时、DZS 项目可用性 2 小时、CZU 英语项目目录及窗口 2 小时、CZU 捷克入口本科／硕士目录 2 小时、CZU 博士学院证据 2 小时；失败单独重试，不能把部分成功报为全量完成。详见 REFRESH_POLICY.md。
逐来源运行记录必须区分 attempt、HTTP 成功、正文解析成功、核验成功和发布成功。HTTP 失败、目标区块为空或分页不完整均不得推进 `lastSuccessAt`；失败来源按 `retryAt` 退避并继续计算 120 小时 SLA。
对幂等官方 HTML／PDF 的请求级重试必须有限：仅传输失败及 HTTP 408、425、429、500、502、503、504 可在 3 秒、12 秒后各重试一次。最终失败仍使整源失败，不推进 `lastSuccessAt`，不以本轮缺席下架旧记录；非短暂 HTTP 状态不得反复请求。请求级重试结束后才进入来源任务的 `retryAt` 退避。
来源内容变化触发关键字段比较和译文过期；不因页面广告或页脚日期变化无意义重译。
岗位逐语种审核记录必须绑定资格正文的源哈希。出现中文标题、沿用英文专名或词典命中均不能自动产生 `verified`；源哈希改变后旧审核失效并重新进入人工队列。
过期归档保留证据；删除／撤回公告要标记状态并复核，不能一直展示为开放。
无站点授权不整站复制内容和图片；发布结构化事实、必要摘要及官方链接。

## 动态岗位发现

岗位列表、分页方式、详情链接规则和 parser 名称登记在 `data/sources/registry.json`，4 小时生产入口从全部已登记来源发现候选，不能靠把已知岗位写成常量冒充动态发现。

- 列表同时处理绝对与相对链接、捷克语与英语路径；分页最多读取注册表允许的页数，并对详情 URL 和稳定 ID 去重。
- 详情正文以标题最后一次正文出现、相邻岗位标题和结构化区块共同定界。关闭、薪酬、学历与博士注册只从该实体范围提取；否定与“硕士／博士二选一”优先于正向关键词。没有资格证据时保留 `unknown` / `unspecified`。
- 稳定 ID 与来源 URL 绑定；若新发现记录与已有人工审核种子相符，沿用审核 ID，但不能沿用不匹配的源哈希审核。
- AVCR 是研究所集合，不是所有岗位的法定雇主。无法从详情辨认实际研究所的候选进入隔离区，不得用 `avcr-central` 代填。
- 只有完整读取本轮所有分页后，旧动态岗位缺席才可记 `unavailable` 并归档；分页失败、429、超时或解析为空不得触发消失下架。
- 仍在完整官方列表、但新的全文判断不再符合研究／技术范围时，标记 `catalogueScopeStatus=excluded` 和范围排除理由；这不等于岗位关闭或官网消失。
- 新候选完成详情解析后仍处于待核验状态。资格、薪酬、三语内容及逐语种源哈希审核全部通过发布契约后，才可进入公开快照。
- 每轮以 MŠMT 54 所高校为岗位来源接入分母，输出已接入学校、未接入学校、独立非高校来源、来源成功数、当前候选数和正式发布数。来源成功率与学校来源接入率不得互相替代。
- 来源注册还要记录覆盖深度：`institution_aggregator` 只表示中央入口聚合多个单位，`faculty` 只表示院系局部入口，`research_network` 不计入高校分母。除非有官方范围证据，`sourceCoverageClaim` 保持 `not_asserted`；中央入口也不能自动写成校内岗位全集。
- Charles University 中央来源须使用官方 AJAX 的 `p` 页码读取完整分页并跟进详情；VUT 校级门户须从公开组件配置读取 GraphQL 全分页和逐项详情；CTU 校级公告须核对列表精确总数并读取每份 PDF，扫描件 OCR 失败即判整源不完整；CZU 须将公共 WP Job Manager 页数、岗位 ID 与同站 REST 全文逐项对齐。UPOL 中央门户须从当前公告列表跟进详情。HTML 实体解码后再生成稳定标题。仅教学、行政或支持岗位，以及正文无法证明研究／技术职责的记录，不得因职位名或背景中出现“研究”而进入候选。

## DZS 项目目录交叉核对

`studyin.gov.cz` 的英文与捷克文目录按 UUID 全量分页抓取，任一页失败、总数在分页期间变化、重复 UUID、两语 UUID 集合不同或学校无法映射，都使本轮失败。每 2 小时任务同时读取其开放申请筛选，但该信号只作发现提示。

DZS 完整返回某轮目录，只能证明该来源快照已完整读取。它不是 MŠMT 法定注册表，也不能替代每所学校／院系公布的入学年度、申请轮次、资格和申请目标。未出现在开放筛选中的记录保持 `not_reported_open`，不能据此关闭。新记录先进入 `candidate_not_published`，完成中文、英文、捷克文与源哈希审核后才可正式展示。

## CZU 本科／硕士项目与申请窗口

`study.czu.cz` 的公开 WordPress REST 目录必须使用响应头总数和页数核对，随后按稳定 post ID 读取每个详情页。详情页是申请日期、学制和学费的字段来源；开放项目页是同时刻的辅助信号，通用招生页用于验证申请系统和申请费。日期计算和开放页计数不一致时保留冲突，不用其中一个静默覆盖另一个。

该来源只声明英语本科／硕士目录范围。不得把 36 条来源完整性写成 CZU 全语言、博士或全校所有 offering 齐全；MŠMT 与 DZS 的 CZU 条目继续作为另外标注的库存／发现层。逐项目 “Apply now” 没有 `href` 时保存 `null`，只把已验证的 UIS 通用入口标为通用入口，不能伪造精确申请链接。所有原文证据和候选仍受三语发布门禁约束。

`studuj.czu.cz` 的公开 REST 当前受访问控制限制，不能据此绕过限制或缩小目录。采集器须先使首页报告总数、公开 programme sitemap 详情数和唯一 post ID 数一致，再读取每个本科／硕士详情的授课语言、学位、院系、学制、窗口、申请目标与证据哈希。页面已展示但无法解析的日期使整轮失败；未展示窗口或项目级申请链接则保留 `unknown` / `null` 和通用 UIS 入口。该来源的完整性只针对网站暴露的本科／硕士目录，排除博士项目。

两条 CZU 源按标题和学位交叉核对英语项目，但各自仍是独立来源快照。2026-09-11 的捷克入口完整读取 129/129 条，其中捷克语 94、英语 35；英语入口为 36 条。两个英文标题存在轻微措辞差异，且英语入口另有一条双学位记录，因此交叉状态为 `disagrees`。不得为了得到一致数字而丢弃、复制或静默改名任何官方记录。

## CZU 博士项目与学院招生证据

博士目录以 MŠMT 紧凑库存中 CZU 的 60 个博士 offering 为固定分母，按学院、授课语言和官方名称逐项匹配 FAPPZ、PEF、FŽP、FLD、TF 与 FTZ 的 2026/27 招生规则。采集器须完整取得注册表基线与配置的九个学院资产；任一 offering 无法匹配、出现未声明额外项目、学院证据失败或窗口文字无法解释时，本轮不成立。官方标题有轻微差异时保留注册表名、来源名和显式别名，不静默改写。

只有截止日而没有开始日的窗口可以在截止后判为关闭，在截止前保持 `unknown`，不能据此标开放。标注“视名额而定”的后续阶段保存 `conditionalOnVacancies=true`，没有学院明确启动证据时保持未知。不得依据上一年曾有第二轮推断本年也会开放，亦不得把本轮未发现下一学年窗口写成“学校尚未发布”。TF 的图像型规则只允许使用已经逐页人工核验、且绑定精确 SHA-256 的转录；文件哈希变化立即使解析失败并进入重新核验。所有博士记录仍进入 `candidate_not_published`，完成事实与 zh-CN / en / cs 源哈希审核后才可进入正式快照。
