## 优先顺序

官方结构化入口／公开 API → 官方 HTML → 官方 PDF → 公开动态页面。聚合站只用于发现，资格与工资回到雇主／学校核验。
采集离线在服务端运行，不让访客浏览器即时爬学校官网。
尊重站点访问条件、robots 和速率；按域名限速，建议起点一个并发、请求间隔 2–5 秒，遇 429 按 Retry-After 退避。

## 难网页必须升级到本机 Scrapling

1. 读取返回状态和正文。HTTP 200 不等于成功，登录页、空壳和验证页都是失败结果。
2. 普通提取缺正文、漏语言／费用／截止等目标区块时，先用 Scrapling get 存原始 HTML。
3. 依赖 JavaScript、分页或动态内容时，用 Scrapling fetch；根据真实页面观察结果指定 wait-selector，不猜选择器。
4. 保留 HTML 证据后再生成 Markdown／结构化数据。必要时使用 CSS selector 精确提取。
5. 同源浏览器英文页与捷克文页可能不同；逐页记录 URL 与实际源语言，不能以 UI locale 代替源语言。
6. 持续失败：记录状态、时间、工具、失败原因与缺失字段，进入人工队列；优先找官方替代页面或 PDF，不编造结果。
7. 不绕过登录权限、付费墙或访问控制；本机工具具备某命令不等于每种用法都必要。

## 本机已核查语法示例

以下 URL 占位必须替换为来源注册表中的官方 URL；示例不会自动执行。

```powershell
scrapling extract get "https://OFFICIAL_HOST/PAGE" "work/raw/page.html" --timeout 30
scrapling extract fetch "https://OFFICIAL_HOST/PAGE" "work/raw/page.dynamic.html" --headless --timeout 45000 --wait 1500
```

get timeout 单位是秒；fetch timeout / wait 单位是毫秒。执行前创建输出目录；所有外部命令须检查退出码。
本次已用 get 实际读取参考站并收到 HTTP 200，提取到内嵌数据和脚本。动态 fetch 仅核查语法，浏览器实际抓取仍待验证。遇环境网络限制应按环境权限申请联网，不能绕过限制或把失败归咎于目标网站。
如缺浏览器依赖，先记录缺什么，再按环境权限安装；不要重复盲目重装全部环境。

## 提取与更新

逐字段保存证据、源语言、内容哈希、抓取时间、解析器版本和规范 URL。
网络成功时间与人工核验时间分开存；抓取成功不得直接标已核验。
固定策略：每隔五天（120 小时）启动一轮覆盖全体已登记捷克高校相关信息的采集。包含院校、专业、招生和已登记招聘来源；失败单独重试，不能把部分成功报为全量完成。岗位关闭另设轻量状态核查与已知截止计时，详见 REFRESH_POLICY.md。
来源内容变化触发关键字段比较和译文过期；不因页面广告或页脚日期变化无意义重译。
过期归档保留证据；删除／撤回公告要标记状态并复核，不能一直展示为开放。
无站点授权不整站复制内容和图片；发布结构化事实、必要摘要及官方链接。

## 新增字段采集

每五天采集高校相关信息时同时提取官方性质、申请开始／结束、年度和原文轮次名，保留申请人范围与补录条件。不能只抓页面最大截止日期。
中留服参考使用官方认证院校查询服务和正式公告，每五天尝试复查已登记参考；受到验证码／访问限制时进入人工核验，不绕过限制、不把失败当作未列入。学校名匹配需人工复核或可靠官方标识。
中留服年度查询数据变化不自动代表学校资格变化。来源及口径见 RECOGNITION_AND_WINDOWS.md。
